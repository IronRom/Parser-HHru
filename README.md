## О проекте

`hh_scraper` обходит сайт hh.ru через headless Chrome (Selenium), собирает вакансии по заданному запросу и сохраняет каждую вакансию как отдельный `.md`-файл с полным описанием, ключевыми навыками и метаданными.

**Почему Selenium, а не API?** hh.ru API возвращает `403 Forbidden` без OAuth-токена. Браузерный подход работает без регистрации приложения.

**Что сохраняется в каждый файл:**
- Название, компания, город, зарплата
- Опыт, занятость, график
- Ключевые навыки
- Полное описание (plain text)
- Ссылка на оригинал

## Начало работы

### Требования

- Python 3.10+
- Google Chrome (устанавливается как обычно)
- `pip` для установки зависимостей

### Установка

1. Клонировать репозиторий или скопировать файлы:
   ```sh
   git clone <repo-url>
   cd DevOpsPath
   ```

2. Установить зависимости:
   ```sh
   pip install selenium webdriver-manager python-dotenv
   ```
   > `webdriver-manager` автоматически скачает подходящий ChromeDriver — ничего дополнительно устанавливать не нужно.

3. (Опционально) Создать `.env` из примера:
   ```sh
   cp .env.example .env
   # отредактируйте .env под свои нужды
   ```

## Использование

```sh
# Простой поиск — 1 страница, вся Россия
python hh_scraper.py "devops engineer"

# Поиск в нескольких регионах, только удалёнка, 3 страницы
python hh_scraper.py "python developer" --areas "москва,спб" --schedule remote --pages 3

# Полная занятость, конкретные регионы по ID
python hh_scraper.py "qa engineer" --areas "1,2,3" --employment full --pages 2

# Без аргументов — берёт всё из .env, запрашивает keyword интерактивно
python hh_scraper.py
```

Файлы сохраняются в папку `vacancies/` (или в `--output`) в формате:
```
YYYY-MM-DD_Компания_Название_вакансии.md
```

## Параметры

| Аргумент | .env переменная | По умолчанию | Описание |
|---|---|---|---|
| `keyword` (позиционный) | `HH_KEYWORD` | — | Поисковый запрос |
| `--pages N` | `HH_PAGES` | `1` | Страниц результатов (макс. 50, ~20 вакансий/стр.) |
| `--output DIR` | `HH_OUTPUT` | `vacancies` | Папка для сохранения файлов |
| `--areas "..."` | `HH_AREAS` | `россия` | Регионы через запятую (имена или ID) |
| `--schedule "..."` | `HH_SCHEDULE` | _(любой)_ | Формат работы через запятую |
| `--employment "..."` | `HH_EMPLOYMENT` | _(любая)_ | Тип занятости |

**Приоритет параметров:** аргументы CLI → `.env` → значения по умолчанию → интерактивный ввод (только для keyword).

## .env файл

Скопируйте `.env.example` в `.env` и заполните:

```env
HH_KEYWORD=devops engineer
HH_PAGES=2
HH_OUTPUT=vacancies
HH_AREAS=москва,спб
HH_SCHEDULE=remote
HH_EMPLOYMENT=full
```

`.env` загружается автоматически при запуске скрипта.

## Регионы

Передаются в `--areas` или `HH_AREAS` через запятую. Можно использовать **русские названия** или **числовые ID** из hh.ru.

| Название | ID | Название | ID |
|---|---|---|---|
| россия | 113 | нижний новгород | 66 |
| москва | 1 | самара | 78 |
| санкт-петербург / спб | 2 | краснодар | 53 |
| екатеринбург | 3 | ростов-на-дону | 76 |
| новосибирск | 4 | уфа | 99 |
| казань | 88 | тюмень | 95 |
| воронеж | 26 | красноярск | 54 |
| волгоград | 24 | пермь | 72 |
| омск | 68 | минск | 1002 |
| киев | 115 | алматы | 160 |

Любой другой регион можно указать по числовому ID из адресной строки hh.ru.

## Форматы работы и занятость

**`--schedule`** — формат работы (можно несколько через запятую):

| Значение | Описание |
|---|---|
| `remote` / `удалённо` | Удалённая работа |
| `fullday` / `полный день` | Полный день |
| `shift` / `сменный` | Сменный график |
| `flexible` / `гибкий` | Гибкий график |
| `fly` / `вахта` | Вахтовый метод |

**`--employment`** — тип занятости (одно значение):

| Значение | Описание |
|---|---|
| `full` / `полная` | Полная занятость |
| `part` / `частичная` | Частичная занятость |
| `project` / `проект` | Проектная работа |
| `probation` / `стажировка` | Стажировка |
| `volunteer` / `волонтёр` | Волонтёрство |
